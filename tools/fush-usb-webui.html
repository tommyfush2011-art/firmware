Device Navigator — USB

This is the original Fush WebUI Navigator layout running over USB serial instead of Wi-Fi. Use the same device screen, nine-button pad, keyboard shortcuts, refresh and automatic reload.

Use desktop Chrome or Edge on localhost. Connect an ESP32-S3 USB data cable and choose the serial port.

USB Navigator requires the updated Fush OS firmware supporting fush navigator start, fush nav and fush screen. The original Wi-Fi file explorer is not included in this USB Navigator page.

Navigator Shortcut

You can use a keyboard for navigating instead of the on-screen buttons

  • Navigating = Arrow Keys
  • Back = Backspace
  • OK = Enter
  • Long Press = M
  • Page Up = Page Up
  • Page Down = Page Down
  • Close Navigator = Escape
  • Reload Screen = R
